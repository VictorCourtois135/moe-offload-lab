    Agents

    Donne un objectif : l'orchestrateur crée ses agents, leur confie le travail et assemble la réponse. Les agents parlent l'un après l'autre sur le même modèle ; compte 10 à 30 minutes pour un objectif à plusieurs étapes. Tes messages de chat passent entre deux tours.

    Aucun dossier autorisé : les agents ne pourront lire ni écrire aucun fichier. Ajoute le dossier de ton objectif dans Outils et MCP, puis « Enregistrer les dossiers ».
    Outils permis aux agents

    Les permissions de l'écran Outils et MCP s'appliquent toujours (« demander » = ton accord à chaque appel).

          Autopilot

          Le modèle optimise son propre moteur pour ce PC. Le code mesure et décide ; il ne garde un réglage que s'il gagne au-delà du bruit, sans perte de qualité. Le moteur lui est réservé pendant le run (20 à 40 minutes).
